# Historias de usuario

- **HU-01** (épica E1, Operador): Como operador, quiero iniciar sesión para usar el sistema de forma segura.
- **HU-02** (épica E1, Administrador): Como administrador, quiero gestionar usuarios y roles.
- **HU-03** (épica E2, Administrador): Como administrador, quiero configurar pisos, zonas y espacios.
- **HU-04** (épica E2, Operador): Como operador, quiero consultar la disponibilidad por piso.
- **HU-05** (épica E3, Operador): Como operador, quiero registrar un vehículo y asignarle un espacio compatible.
- **HU-06** (épica E4, Operador): Como operador, quiero calcular el valor de la estadía cuando el cliente solicita salir.
- **HU-07** (épica E5, Operador): Como operador, quiero confirmar el efectivo recibido y dejar constancia del cobro.
- **HU-08** (épica E3, Operador): Como operador, quiero cerrar la salida después de confirmarse el resultado de Billing.
- **HU-09** (épica E4, Administrador): Como administrador, quiero actualizar tarifas sin alterar liquidaciones históricas.
